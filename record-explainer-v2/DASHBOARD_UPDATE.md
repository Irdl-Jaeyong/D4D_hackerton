# 최종 목표 시안의 웹페이지 반영

사용자가 ‘대크크’에서 확정한 `generated_images/exec-a10f130d-3597-4281-b210-74d548399d04.png`을 디자인 기준으로 사용했다. 네이비·시안 색상, IRDL 로고와 하단 영문명, 상단 지표, 왼쪽 검색·그룹 목록, 중앙 항만 개념 이미지와 최근 기록, 오른쪽 원본·LLM 채팅을 반영했다. 헤더 합성 데이터 배지는 없다. 시안의 100건·4그룹 숫자를 하드코딩하지 않고 현재 데이터에서 지표를 계산한다.

`index.html`, `dashboard.css`, `ui.js`, `state.js`를 수정했다. 기록 ID·내용 검색과 읽음 필터를 함께 적용하며 최근 기록도 같은 결과를 표시한다. 원본 근거 이동은 검색을 초기화해 잘못된 선택을 방지한다. 기존 읽음·질문·요약·재생·측정과 별도 Gazebo 진단을 유지한다. 작은 화면은 2열 또는 1열로 배치한다.

중앙 이미지는 imagegen 내장 도구로 목표 시안의 민간 항만 부분을 별도 배경으로 생성했다. 최종 자산은 `assets/harbor-concept.png`, 생성 원본은 `generated_images/exec-c2c2f476-80cb-4a8c-907c-d87153c02b9f.png`다. 요청은 ‘중앙의 민간 항만 그림만 별도 가로 이미지로 재현, 어선 두 척·부두·해안 마을·산·맑은 하늘 유지, UI·문자·로고·군사 요소 제외’였다. 실시간 Gazebo 화면이나 기록 위치와 연결된 이미지가 아니라는 안내를 표시한다.

Python 회귀 검사 26개, 기존 JavaScript 상태 검사 6개, 추가 검색·필터 결합·선택 대체 검사, UI 구문·HTML ID 참조 검사가 통과했다. CSS·이미지의 고정 HTTP 경로를 추가하고 200 응답과 파일 노출 제한을 검사했다. 실제 브라우저 시각·상호작용은 기존 접근 제한으로 미검증이며 우회하지 않았다.

## 현재 실행

사용자 요청으로 localhost `http://127.0.0.1:18081`에 실행했다. 기존 모델·웹 작업을 보존하기 위해 프로젝트 모델은 11435를 사용한다. `demo.py`에 `--model-port`, `--web-port` 옵션을 추가했고 기본 포트와 기존 사용법은 유지한다. 명령:

```bash
.venv/bin/python record-explainer-v2/demo.py start --model-port 11435 --web-port 18081
```

시작 도구 터미널 세션 ID는 29775다. 종료 요청 시 해당 세션에 Ctrl+C를 전달하면 자신이 시작한 프로세스만 정리한다. 이번에는 페이지를 볼 수 있도록 실행을 유지한다. 실제 HTML·CSS·JS·이미지·기록 API의 HTTP 200을 확인했고 `dashboard-http-results.json`에 기록했다. 운영체제 서비스 등록·외부 공개·다른 프로젝트 실행은 없다.
