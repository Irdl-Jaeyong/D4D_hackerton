# 전체 합성 기록 요약 검증 — 2026-10-10

## 변경

`app.py`에 구조화된 전체 요약, `/api/summary`, 전체 기록 커버리지·시각·기록별 인용 검사와 공통 Ollama 요청 처리를 추가했다. 기존 개별 설명은 유지했다. `index.html`, `ui.js`에 전체 요약 버튼·결과·근거 이동·재시도 안내를 추가했다. 전체 원본은 변경하지 않으며 개별 설명과 중복 생성 요청을 막는다. 사용자 입력이나 외부 데이터를 전체 요약에 주입하는 기능은 없다.

## 확인

- 기존 17개와 새 요약 검사 5개를 합한 Python unittest **22개 통과**. 명령: `../.venv/bin/python -m unittest -v test_api test_demo test_simulator test_summary`.
- 새 검사는 전체 3건 단일 요청, 원본 보존, 누락·중복·교차 인용·잘못된 시각·빈 요약 거부, 임의 입력 거부, 개별 설명과 공통 잠금 및 장애 후 회복을 확인했다.
- JavaScript `new Function` 구문 검사 통과. DOM·화면 동작 확인은 아니다.
- 설치된 Qwen 모델 실제 응답 **HTTP 200**, 약 **6.57초**. 세 기록 모두 ID·시각·인용 검사 통과, 원본 조회 결과 변경 없음. 이번 응답은 원본 문장을 거의 그대로 정리했으며 복잡한 종합 추론이나 품질 향상을 입증하지 않는다.

실제 응답과 종료 증거: `summary-live-results.json`, 모델 로그 `summary-live-ollama.log`.

## 실행 환경과 보존

기존 localhost 11434에는 별도의 Ollama 0.40.1/minicpm 모델이 있어 기존 시작 도구의 사전 점검이 실행을 거부했다. 이 기존 작업은 수정·종료하지 않았다. 프로젝트 Ollama와 Qwen을 임시 localhost 11435에 실행하고 **시험 프로세스 내에서만** 모델 URL을 바꿔 새 API를 ASGI로 검증했다. 소스 기본 URL은 11434로 유지한다. 자신이 실행한 모델 서버는 정상 종료 코드 0, 11435 닫힘을 확인했다. 새 설치·다운로드·Gazebo 실행·실제 장치 연결은 없었다.

사용자 시연 시 기본 11434가 다른 작업에 쓰이고 있으면 시작 도구가 실행을 거부할 수 있다. 기존 작업을 임의 종료하지 않는다. 실제 브라우저 검증은 기존 접근 제한 때문에 미실행이며 우회하지 않았다. 화면에서 전체 버튼·근거 이동·필터 독립·실패 재시도는 수동 확인 대상이다.

## 범위

합성 A/B/C 텍스트 기록을 한 번에 표시하는 데모다. 실시간 상태 데이터 수집, 자율 이동, 군사 기체의 운용·제어는 구현하지 않았다. 일반 Gazebo 진단은 계속 별도다.
