# 사용자가 직접 확인할 화면 체크리스트

에이전트의 실브라우저 검증·캡처는 미실행이다. 아래는 사용자가 데모 시작 후 직접 확인할 항목이며 완료 결과가 아니다.

- [ ] 상단에 합성 데이터·실제 장치/ROS 미연결 및 Gazebo 통계 별도 진단 표시가 있다.
- [ ] A/B/C 카드 선택 시 원본 ID·시각·상태·내용이 해당 카드와 일치한다.
- [ ] A를 읽음 표시해도 연결 실패 상태와 해결 정보 없음이 그대로다. 반복 클릭은 중복 변경하지 않는다.
- [ ] 읽음/읽지 않음 필터 및 결과가 없는 상태가 올바르게 표시된다.
- [ ] 필터 초기화는 읽음이나 이전 질문을 지우지 않는다.
- [ ] LLM 설명 영역을 끄고 켜도 원본·읽음 상태가 바뀌지 않는다.
- [ ] B에 정상 여부를 질문하면 설명과 원본 인용·ID·시각·생성 시각이 별도로 표시된다.
- [ ] 생성 중 연속 클릭해도 중복 요청이 발생하지 않는다. 다른 카드를 선택해도 이전 질문의 결과는 원래 질문 대상에 연결된다.
- [ ] 빈 질문은 보내지지 않는다. 같은 질문을 다시 할 수 있다.
- [ ] 근거 없는 일반 질문은 확인 불가 또는 검증 오류로 나타난다.
- [ ] 모델 실패 안내가 나와도 이미 표시된 원본 기록을 선택하고 확인할 수 있다.
- [ ] 긴 답변과 좁은 화면에서 가로 넘침·겹침이 없고 키보드 Tab으로 조작할 수 있다.
- [ ] 새로고침은 질문 이력을 지우지만 서버의 읽음 표시는 유지한다. 서버 재시작하면 읽음도 초기화된다.
- [ ] 종료 터미널에서 Ctrl+C 후 localhost 서버 두 개가 종료된다.
- [ ] 초기 기록 조회 실패 후 기록 새로고침으로 재시도할 수 있고, 새로고침 실패 시 기존 원본은 유지된다.
- [ ] 읽음 표시 요청 중 카드를 바꾸고 돌아와도 같은 요청을 중복 제출할 수 없다.
- [ ] 실패한 A 질문 뒤 B를 선택하고 재시도하면 새 이력은 A 근거에 연결되고 B 원본 선택은 유지된다.
- [ ] 각 질문의 대기·완료·실패 표시가 순서대로 남고 원본 확인 버튼이 정확한 기록을 연다.
- [ ] 키보드로 카드를 선택한 뒤 포커스가 사라지지 않는다. 읽음 필터에서 읽음 처리로 카드가 사라지면 다음 카드 또는 필터에 포커스가 간다.
- [ ] 측정 시작 후 조건 전환이 잠기며 측정 종료 후 다시 변경할 수 있다.
- [ ] 완료 측정 CSV를 열어 조건·시간·횟수만 있고 질문 내용이나 개인 정보가 없음을 확인한다.

문제가 있으면 항목 번호·실행 시각·오류 문구를 기록한다. 비밀값이나 개인 정보를 질문에 넣지 않는다.

## 추가 일반 진단 영역

- [ ] 지정한 일반 장면을 실행하면 통계 수신 표시와 시뮬레이션 시각이 갱신된다.
- [ ] 장면 종료 후 현재 값은 없어지고 이전 값은 마지막 수신 통계·실시간 아님으로 표시된다.
- [ ] 장면 없이 처음 열면 미수신으로 표시되며 정상 실행·장치 연결을 단정하지 않는다.
- [ ] 웹 API에 연결할 수 없으면 진단 현재 값 표시를 중단한다.
- [ ] 실제 통계는 A/B/C 합성 기록이나 LLM 질문 근거로 들어가지 않는다.
