# 외부 접근 상황과 운용자 대형 선택

상황 발생은 외부 모의 선박만 생성하며 함대 대형을 바꾸지 않는다. 운용자가 USV/UAV 대형 버튼을 직접 선택하면 함선 상대 대형이 점진적으로 전환된다. 후방 상황에서 UAV V자는 후방을 향하고 전방 상황에서 UAV 삼각형은 전방 관측 위치로 전개한다.

| 상황 | 외부 접촉 | 참고 대형 (USV / UAV) |
| --- | --- | --- |
| 주변 미식별 접촉 | 측면 1척 | 원형 / 다중 링 |
| 전방 고속 접근 | 전방 1척 | 부채꼴 / 삼각형 |
| 양측 동시 접근 | 좌·우현 2척 | 2열 / 박스 |
| 후방 추적 접근 | 후방 1척 | V자 / V자 |

대응안 실행은 선택 사항이다. 실행하면 UAV는 접촉을 지속 추적하고 USV는 접촉과 함선 사이 경계선을 유지한다. 실행 중 대형 버튼을 누르면 수동 운용으로 인계하고 출동 기체는 선택된 대형에 복귀한다. 외부 접촉은 계속 표시한다. 상황 종료로 접촉을 제거할 수 있다.

시작할 때 `startup_mode: normal` 설정으로 이전 상황·모의 고장·에너지 추정 이력을 초기화하고 원형 USV·반구 UAV 정상 호위로 시작한다. 120초 동안 정상 상태를 보여준 뒤 첫 상황이 발생한다. `startup_mode: resume`으로 바꾸면 이전 관제 상태를 복원한다.

자동 상황 생성은 120초 간격, 승인 대기 최대 4건, 표시 상위 3건이다. 구조·장애물은 이전 API 호환용으로 유지하지만 자동 생성 후보에서 제외했다. 고장은 자동 생성 후보에서 제외하며 기존 고장 기체 표현은 유지한다.

설정은 config/defense_scenarios.json (방위·접근 속도·거리·참고 대형), config/approval_risk.json (규칙 점수), config/auto_scenarios.json (주기·최대 건수)에서 수정한다. 위험도는 규칙 기반이며 실제 적대 의도를 확정하지 않는다.

외부 소형정은 원본 12m 곡면 메시, 갑판·고무 칼라·유리·선외기·항해등·항적으로 표현한다. 3D 카메라와 지도 범위는 외부 접촉을 포함하며 접촉 식별·거리 표시는 화면 오버레이다.

## 시뮬레이션 범위

외부 접근 선박의 항로와 파도에 따른 자세, UAV 이동은 위치 갱신 기반 시연이다. USV는 기존 부력·추진력 기반 제어를 유지한다. 접촉 항로는 안전 거리를 유지하는 비무장 접근 시나리오이며 실제 센서 탐지·분류, 충돌 동역학, 무장 교전은 구현하지 않는다. 따라서 이 결과를 실제 방어 성능 검증으로 해석하지 않는다.
