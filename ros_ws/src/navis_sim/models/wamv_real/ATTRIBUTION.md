# WAM-V 16 ft USV visual asset

Source: Open Robotics VRX, wamv_description/models/WAM-V-Base.
https://github.com/osrf/vrx/tree/7609d1bd90ce7edb29d040a082f949e8b089c864/vrx_urdf/wamv_description/models/WAM-V-Base
Revision: 7609d1bd90ce7edb29d040a082f949e8b089c864. Retrieved 10 October 2026.
License: Apache-2.0, original LICENSE retained.

The mesh, UVs and Albedo/Normal/Roughness/Metalness maps are from VRX.
The COLLADA centimetre unit and root 100x export matrix have been normalized
to equivalent metre units (root translation multiplied by .01). No shape or
texture rescaling is used. The mesh envelope is about 5.01m long × 2.49m wide.
The source describes a 16-foot WAM-V. This scene uses the authentic base
visual, not the full VRX propulsion, buoyancy, sensor or control systems.
